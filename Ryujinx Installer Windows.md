## 🛠 Step-by-Step Setup

### Step 1 — Download and Extract
Save `Ryujinx-Installer.zip` (~120 MB) and unpack it. **No password required.**

### Step 2 — Install .NET Runtime
Ryujinx requires **.NET 8.0** or newer. Download it from the official Microsoft website.

### Step 3 — Run the Installer
Right-click on `Ryujinx-Setup.exe` → **Run as Administrator**.

### Step 4 — Add Firmware and Keys
Open `File → Open Ryujinx Folder` and place `prod.keys` and firmware files into the `system` folder.

### Step 5 — Configure Input
Go to **Options → Input Settings** and map your keyboard or controller.

### Step 6 — Launch Your Game
Click **File → Load Application** and select your game file (`.nsp`, `.xci`, or `.nro`).

## 🔧 Troubleshooting

|-------------|--------------|

| **"No keys found"** | Place `prod.keys` in `system` folder |
| **Game crashes on launch** | Update GPU drivers |
| **Low FPS** | Enable Vulkan backend in settings |
| **Audio issues** | Change audio backend to SDL2 |
| **Black screen** | Disable "Docked Mode" in settings |
